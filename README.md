# Connecto - Real Time Chat Application

## Overview
Connecto is a real-time chat application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js) and Socket.io.

## Features
- User Authentication
- Profile Management
- Friend Requests
- Real-Time Messaging
- Online Status Tracking
- Cloudinary Avatar Uploads
- MongoDB Atlas Integration

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- Socket.io
- Cloudinary
- Redux Toolkit

## Installation

### Client
cd client
npm install
npm run dev

### Server
cd server
npm install
npm run dev
